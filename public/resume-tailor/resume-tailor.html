PrivateApply Local TeX Compilation Companion Setup

To compile your LaTeX résumé directly to PDF without uploading your source to cloud servers, install the local native messaging companion:

Windows Setup:
  1. Install a TeX toolchain (e.g. MiKTeX via winget): 
    winget install MiKTeX.MiKTeX
  2. Run the Windows installation script (PowerShell): 
    powershell -ExecutionPolicy Bypass -File .\companion\install.ps1
    (Or simply double-click companion\install.bat)
  3. Restart your browser and reload this page.
Linux Setup:
  1. Install a TeX engine: sudo dnf install texlive-scheme-basic latexmk (Fedora) or sudo apt install texlive-latex-base latexmk (Ubuntu/Debian)
  2. Run the user-level installation script: 
    ./companion/install.sh
  3. Reload this page.

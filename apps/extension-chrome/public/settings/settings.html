Important Security & Privacy Notice
GitHub Secret Gists are unlisted, but NOT end-to-end encrypted. GitHub and automated scanners can potentially scan, index, or inspect Gist contents. Storing confidential personal identifiers, passport numbers, and contact details in a Gist is done strictly at your own risk.

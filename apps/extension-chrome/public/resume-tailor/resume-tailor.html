PrivateApply Linux Compilation Companion Setup

To compile your LaTeX résumé directly to PDF without uploading your source to cloud servers, install the local Linux native messaging companion:

  1. Open your terminal and run the user-level installation script: 
    cd /home/box/Documents/offlyn-apply && ./companion/install.sh
  2. Ensure a TeX engine is installed: sudo dnf install texlive-scheme-basic latexmk (Fedora) or sudo apt install texlive-latex-base latexmk (Ubuntu/Debian)
  3. Reload this page. The companion connects automatically via Chrome Native Messaging.
